# G0.22 — Correção de dependências dos relés

O instalador do GitHub não havia publicado os arquivos da G0.21 porque a validação anterior falhou.

Este ZIP restaura as três cenas LV1/LV2/LV3, o controlador, shaders, 12 GLBs e atualizações do HUD/Central.

## Instalação sequencial
1. Deixe apenas este ZIP na raiz do GitHub e execute o instalador universal.
2. Depois de validar verde, remova o ZIP e envie novamente o pacote da G0.22 Parte 3.
3. Execute o instalador e valide novamente. Não volte a instalar Partes 1 e 2.

Os dados e GLBs de naves/armas não foram alterados neste hotfix.
