# Stellar Legacy Godot G0.5 - correcao de importacao

## Erro corrigido

O Godot 4.5.2 interrompia a importacao de `scripts/main.gd`, linha 114:
`Cannot infer the type of "blocked" variable`.

A verificacao de abertura do HUD passou a usar `var blocked: bool`, e a consulta
do menu agora converte explicitamente seu retorno dinamico para `bool`.
A logica de movimento e ataque permanece inalterada.

## Como instalar

O workflow rejeitou o ZIP antigo e nao publicou os scripts G0.5. Exclua
o ZIP com falha da raiz do GitHub antes de enviar o novo: o workflow aceita
exatamente um ZIP por execucao. Suba o **COMPLETO corrigido** ou a
**ATUALIZACAO corrigida** para a raiz e rode Actions novamente.

## Validacao

Esta correcao foi conferida por analise de codigo e validacao de integridade
do ZIP. A confirmacao da compilacao/importacao depende de um novo workflow
Godot (nao disponivel para execucao local nesta sessao).
